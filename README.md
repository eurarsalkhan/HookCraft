AI Hook Generator is a simple web app that helps you create catchy, high-converting text hooks in seconds using AI.

Whether you’re working on ads, social media, YouTube, or sales pages, this tool makes it easier to come up with strong, engaging headlines.

The project uses OpenAI for AI content, Supabase for user authentication, and Stripe for payments.

✨ What You Can Do With It

Generate powerful text hooks with AI

Create an account and log in securely

Unlock features with Stripe payments

Save and manage your usage

Use Google API for extra integrations

Perfect for:

Marketers

Content creators

Business owners

Copywriters

🛠 Tech Stack

JavaScript – backend logic

OpenAI API – AI text generation

Stripe – secure payments

Supabase – authentication & database

Google API – additional services

HTML / CSS / JS – frontend

Getting Started

1) Clone the repository

git clone https://github.com/your-username/ai-hook-generator.git


2) Install dependencies

npm install


3) Create a .env file

OPENAI_API_KEY=your_openai_key
STRIPE_SECRET_KEY=your_stripe_key
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_key
GOOGLE_API_KEY=your_google_key


4) Run the project

npm start

🔐 Authentication

User accounts are handled using Supabase, keeping login data secure and easy to manage.

💳 Payments

Stripe is used to manage payments so users can unlock AI features safely and smoothly.
